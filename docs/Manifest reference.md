# Manifest reference

Generated by [generate_manifest_guide.py](../scripts/generate_manifest_guide.py), whose maintained explanations are checked against all current nested fields. These are operational metadata, not biological table columns. `[*]` means an array element; `<source>`, `<filename>`, `<package>`, `<species>`, `<asset>`, `<label>` and `<check>` denote variable map keys. Types are observed JSON/Python representations (`dict` object, `list` array, `str` text, `int` integer, `bool` boolean, `NoneType` null).

A missing key is unrecorded for that workflow/provider/version. A present null is unavailable or not applicable; metadata does not consistently distinguish those states. Empty arrays/maps mean no recorded entries, not necessarily absence of biological evidence. Status labels are interpreted within their enclosing workflow. Timestamps are UTC strings where recorded; sizes are bytes; row/cell/count metrics are integers. Checksums are hexadecimal SHA-256 unless an upstream checksum explicitly carries a different prefix.

Do not hand-edit hashes after changing code: use supported regeneration and validation. Build inputs currently include local absolute paths; these are provenance, not portable download instructions, and require privacy review before publication. See [Script guide](Script%20guide.md) and the [field guide](Database%20dictionary.md).
